# data10-07 · 협력사 공정불량 분석·품질개선 Master Plan

## 실행 방법

**온라인 시연: https://aebonlee.github.io/data10-07/** (가상 데이터로 흐름을 보는 용도)

### 사내망에 두고 쓰기

1. GitHub 에서 「Code → Download ZIP」으로 받아 압축을 풉니다.
2. 폴더를 **통째로** 사내 공유 드라이브나 사내 웹서버(IIS·Apache·nginx 등의 정적 폴더)에 둡니다. `index.html`·`css/`·`js/`·`vendor/` 가 같은 자리에 있어야 합니다.
3. `index.html` 을 엽니다(공유 드라이브는 더블클릭, 웹서버는 그 주소). 설치·인터넷 연결이 필요 없습니다.
4. 데이터는 **각 PC 의 브라우저 안에만** 저장됩니다. 다른 사람과 나누거나 PC 를 바꿀 때는 「불량 등록 → 백업 · 복원」의 JSON(전부)·엑셀(불량 목록) 파일을 사내 공유 폴더로 주고받습니다. 브라우저 기록을 지우기 전에는 꼭 백업을 받아 두세요.
5. AI 는 선택입니다. 사내에서 쓰도록 허용된 AI 서버가 있을 때만 「설정 → AI 연결 설정」에 주소를 적습니다. 비워 두면 어떤 외부 주소도 부르지 않습니다.

처음 열면 대시보드입니다. **「불량 등록」** 에서 바로 적기 시작하거나, **「예시 데이터로 시작」** 으로 가상 151건(협력사 C 의 용접불량이 8~10월에 늘어나는 것, 같은 품번 반복, 어느 유형에도 맞지 않는 내용 3건을 일부러 심음)을 넣어 흐름을 먼저 볼 수 있습니다.
