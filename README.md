# data10-07 · 협력사 공정불량 분석·품질개선 Master Plan

협력사 공정불량 Raw data(Excel)를 올려 불량유형을 분류·분석하고, 불량유형별 개선대책 Master Plan 초안(AI 반자동)을 만들어 간트차트로 계획·실적을 관리하고 Excel 보고서로 내보내는 브라우저 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 이준호 |
| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-10-20) — https://aebonlee.github.io/data10-07/ |
| 다음 개발 | 2단계 — 실제 Raw data·불량유형 코드표·보고서 양식 반영, 공유 DB·로그인(사외망 팀·협력사 공유), 과제 02(APQP 서류 정합성)와 협력사 품질 포털로 묶기 |

> 실제 공정불량 Raw data 는 아직 받지 않았습니다. 들어 있는 예시는 **협력사 A~F · 품번 TP-… 로 지은 가상 데이터**입니다. 회사 자료는 이 리포에 넣지 않습니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data10-07/**

처음 열면 대시보드입니다. **「예시 데이터로 시작」** 을 누르면 가상 151건이 들어가고 불량 분석 화면으로 넘어갑니다(협력사 C 의 용접 균열이 8~10월에 늘어나는 것, 같은 품번 반복, 어느 유형에도 맞지 않는 문제점 3건을 일부러 심어 두었습니다).
실제로 쓸 때는 「RAW DATA 업로드」에서 발생일자·품명·품번·문제점·협력사 열이 있는 Excel 을 고르면 됩니다. 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS).

| 화면 | 하는 일 |
|---|---|
| 대시보드 | 불량 발생 건수·협력사 수·개선 필요 항목·개선활동 완료, 협력사별 건수, 불량유형 파레토, 월별 추이, 개선 필요 항목 TOP 8, 협력사별 추진현황, 일하는 순서 |
| RAW DATA 업로드 | Excel·CSV 여러 개 · 제목 줄 아래 머리행 자동 찾기 · 다른 열 이름(업체명·불량내용·P/N 등) 자동 연결 · 직접 고르기(다음 파일에 기억) · 같은 행 건너뛰기 · 빈 양식 · 분류 결과 내보내기 |
| 불량 분석 | 협력사·기간 거르기 · 유형 파레토 · 월별 추이 · 협력사×유형 교차표 · 개선 필요 항목(반복 발생·증가 추세·반복 품번, 근거 숫자) · 반복 품번 · 분류 결과(키워드 근거, 행마다 유형 직접 고르기, 키워드 바로 더하기) |
| MASTER PLAN | 협력사·계획 착수 기준일·분석기간 → 「분석 및 초안 생성」 · 지표 6개 · AI 불량 분석 요약 칩 · 통합 개선대책 Gantt(주차/월, 계획·실적 막대, 완료 녹색·미완료 주황·보류 보라, 오늘 선) · 행을 누르면 오른쪽 칸에서 계획·실적 입력 · 「개선활동 추가」「계획 확정」「AI 초안 다시 불러오기」「Excel 보고서 다운로드」 · AI 로 구체화(프롬프트 복사 → 답 붙여 넣기 → 표 읽기 → 반영, **협력사·품번은 별칭으로 가림(기본)**, 선택: 설정한 AI 서버로 자동 보내기) |
| 추진현황 | 전체 협력사 개선활동 — 상태·지연 거르기, 협력사별 진행 막대, 간트(협력사 칸 포함), 행 눌러 실적 입력 |
| 보고서 출력 | 협력사 하나 또는 전체 — Excel 5시트(요약 · Master Plan(주차 칸 ○ 계획 ● 실적) · 개선대책 상세 · 불량 상세 · 확정 이력), 미확정 경고, 인쇄/PDF |
| 설정 | 불량유형 키워드 사전·기본 대책(순서 = 우선순위), 담당부서 목록, 개선 필요 항목 기준, 별칭 가리기, AI 연결(OpenAI 호환 주소·모델·본인 키, 기억은 선택), 사외망 안내, JSON 백업·되살리기 |

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음, 33개)
- 샘플 파일 다시 만들기: `node scripts/make-samples.js` → `samples/예시_협력사_공정불량_RawData.xlsx`·`.csv` (다시 읽어 원본과 같은지 확인)
- 브라우저 점검(선택): `PLAYWRIGHT_CORE=<playwright-core 경로> node scripts/check-browser.mjs` — 주요 흐름 + 6가지 폭 × 7화면 가로 넘침
- 기획서 Word 만들기: `python3 scripts/md2docx.py docs/01_프로젝트_기획서.md` (python-docx)
