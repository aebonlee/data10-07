## 결정과 이유

- **파일 업로드 대신 화면 입력 + 엑셀 붙여넣기를 기본으로 했습니다.** 업로드가 어렵다는 답은 「정리된 파일이 없거나 반출이 어렵다」는 뜻으로 읽었습니다. 붙여넣기는 파일을 고르지 않고 엑셀에서 복사만 하면 되어, 이미 엑셀에 적어 둔 것이 있으면 가장 빠릅니다. 머리행이 있으면 열 이름으로 맞추고, 없으면 등록 화면과 같은 순서로 읽습니다. 날짜처럼 읽히는 칸이 있는 줄은 머리행으로 보지 않게 했습니다 — 데이터 첫 줄의 「협력사 A」가 「협력사」 열 이름으로 오인될 수 있어서입니다.
- **화면 등록은 같은 내용이 있어도 그대로 더합니다.** 붙여넣기·파일은 같은 줄을 한 번만 넣지만(같은 표를 두 번 붙여 넣는 실수 방지), 사람이 한 건씩 적은 것은 의도한 것으로 보고 넣은 뒤 「같은 날 같은 내용이 이미 N건」이라고만 알립니다.
- **유형은 등록할 때 고르게 하되, 비워 두면 내용 키워드로 나눕니다.** 입력 중에 「자동 분류: 용접불량 (키워드 용접, 균열)」을 미리 보여 줘서 고를지 말지 정할 수 있게 했습니다. 붙여 넣은 표의 불량유형 칸은 띄어쓰기·「/」「·」를 무시하고 8종 이름에 맞춥니다(「위치·치수」「용접 불량」). 맞는 이름이 없으면 그 칸 글자도 키워드 분류에 함께 씁니다.
- **도장·외관·녹은 8종에 없어 「기타」의 키워드로 두었습니다.** 따로 나누는지는 다시 여쭙니다(기획서 10장 ⑧). 「도막 두께 부족」이 위치/치수의 「두께」에 걸리지 않게 「도막 두께」를 기타 키워드로 넣었습니다(긴 키워드가 이김).
- **Excel 서식은 SheetJS 를 바꾸지 않고 덧칠했습니다.** 서식을 쓰는 다른 판(스타일 지원판)을 받으려면 외부에서 새 파일을 가져와야 하고, 사내망 전용 도구에 의존을 늘리지 않으려 했습니다. 만든 xlsx 를 SheetJS 의 압축 도구로 열어 styles.xml 에 굵은 글꼴·칸 색·테두리를 더하고 해당 칸에 번호만 붙입니다. 테스트에서 다시 열어 굵은 글꼴·색·날짜 형식·틀 고정을 확인하고, openpyxl 로도 열어 봤습니다.
- **보고서의 날짜는 엑셀 날짜(숫자 + yyyy-mm-dd 형식)로 넣습니다.** 글자로 넣으면 엑셀에서 날짜 거르기·정렬이 되지 않아서입니다.
